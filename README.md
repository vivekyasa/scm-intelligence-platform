# Supply Chain Planning Intelligence Platform

Ask questions in plain English about supply chain planning data and company planning policies.
A Gemini-powered agent chooses between two tools: guarded read-only SQL over a Postgres database,
and pgvector search over policy documents. Answers include sources.
